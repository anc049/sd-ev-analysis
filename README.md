# San Diego County EV Analysis (2018-2024)

Interactive data visualization project analyzing electric vehicle adoption trends in San Diego County.

## Project Overview
This analysis examines vehicle registration data across 113 ZIP codes in San Diego County, tracking the growth of Battery Electric, Hybrid Gasoline, Gasoline, and Hydrogen Fuel Cell vehicles from 2018 to 2024.

## Key Findings
- Battery Electric vehicles grew 570% from 2018-2024
- Coastal regions show 2-3x higher EV adoption than inland areas
- Despite highest electricity prices in the US, EVs maintain 30% fuel cost advantage

## Data Sources
- California DMV Vehicle Registration Data
- US Energy Information Administration (EIA)
- California Energy Commission
- Alternative Fuels Data Center (AFDC)

## Tools Used
Python, Pandas, Plotly, Matplotlib, Seaborn
